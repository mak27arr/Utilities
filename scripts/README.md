# Збір фото лічильників

## Локальне сортування фото через CLIP

`filter_meter_images.py` рекурсивно переглядає зображення в `data` (або в папці з `--input`) і класифікує їх локально моделлю `openai/clip-vit-base-patch32`. При першому запуску ваги завантажуються й кешуються. Після цього модель можна запускати локально. Вихідні зображення не видаляються: у `data/meter_filter_results` створюються копії в `keep`, `review` і `reject`, а `filter_results.csv` зберігає оцінки та відповідність файлів.

Одноразове встановлення залежностей:

```powershell
py -m pip install torch transformers pillow
```

Коли завантаження зображень завершиться, запусти з кореня репозиторію:

```powershell
py scripts/filter_meter_images.py --input data --output data/meter_filter_results
```

За замовчуванням CLIP лишає фото в `keep` за score від `0.65`, відправляє в `reject` за score до `0.30`, а проміжні випадки — в `review`. Це відносні оцінки моделі, не гарантовані ймовірності: перед видаленням невідповідних оригіналів переглянь `reject` і `review`. Модель сортує фото за загальною схожістю з описами, але не знаходить рамку показника для YOLO. Використовуються англомовні описи, бо картка базової CLIP-моделі обмежує її рекомендоване використання англійською.

## Через Google Images або Bing Images у браузері

`download_meter_images_browser.py` відкриває видимий браузер Playwright, виконує пошук лише українськими запитами, прокручує сторінки результатів і послідовно завантажує знайдені зображення у звичайну папку. За замовчуванням використовується Google Images і встановлений Microsoft Edge.

Одноразове встановлення Playwright:

```powershell
py -m pip install playwright
```

Запуск із кореня репозиторію:

```powershell
py scripts/download_meter_images_browser.py --engine google --browser msedge --output data/meter_images_browser --limit 1000
```

Або Bing Images:

```powershell
py scripts/download_meter_images_browser.py --engine bing --browser msedge --output data/meter_images_browser --limit 1000
```

Можна вказати `--browser chrome`, якщо встановлено Google Chrome, або `--browser chromium` для браузера Playwright (для нього додатково виконайте `py -m playwright install chromium`). `--limit` задає загальну кількість нових файлів, `--per-query-limit` обмежує кількість на один пошуковий запит, `--delay` задає паузу між завантаженнями в секундах. Якщо з'явиться CAPTCHA, скрипт залишить сторінку відкритою і чекатиме її ручного проходження до 600 секунд; це можна змінити, наприклад, параметром `--captcha-timeout 900`. Після розв'язання CAPTCHA збір продовжиться автоматично. Зображення зберігаються безпосередньо в `--output`, а `manifest_browser.csv` містить український запит, URL зображення та сторінки-джерела, хеш і відомості про застосований фільтр ліцензії. Повторний запуск пропускає вже відомі URL і точні дублікати.

Пошук не обмежується ліцензійним фільтром, щоб не втрачати більшість результатів. Перед використанням зображень потрібно окремо перевірити умови на сторінці першоджерела. Якщо пошуковик обмежить завантаження (HTTP 429/503), скрипт дотримається `Retry-After` до 600 секунд або використає повторні паузи 2, 5, 8 і 15 секунд. CAPTCHA потрібно пройти вручну у видимому браузері; скрипт не обходить перевірки.

## Через відкриті каталоги

`download_meter_images.py` паралельно шукає зображення за українськими запитами у Wikimedia Commons та Openverse і зберігає їх у звичайну папку. Commons API лишається в скрипті; Openverse додає результати з інших каталогів відкрито ліцензованих медіа. Скрипт не потребує сторонніх Python-пакетів.

Якщо Python повідомляє про помилку сертифіката HTTPS, оновіть CA-сертифікати:

```powershell
py -m pip install --upgrade certifi
```

Скрипт автоматично використовує пакет `certifi`, коли він встановлений; перевірка TLS залишається увімкненою.

Запуск із кореня репозиторію:

```powershell
py scripts/download_meter_images.py --output data/meter_images --limit 1800
```

`--limit` задає кількість зображень окремо для кожного джерела. Наприклад, `--limit 1800` означає до 1800 з Commons і до 1800 з Openverse. За замовчуванням — до 1500 з кожного джерела у `./meter_images`. Для кожного файла скрипт додає рядок у `manifest.csv` із джерелом, запитом, сторінкою, автором і ліцензією. Повторний запуск пропускає вже відомі сторінки й точні дублікати за SHA-256.

Між завантаженнями на кожному джерелі є пауза 2 секунди. Якщо API повертає HTTP 429 або 503, скрипт поважає `Retry-After` (до 600 секунд); якщо заголовка немає — повторює через 2, 5, 8 і 15 секунд, після чого пропускає запит.

Приймаються лише JPEG, PNG і WebP з ліцензіями Public Domain, CC0, CC BY або CC BY-SA. Зображення меншого розміру за 320 пікселів по одній зі сторін пропускаються. Wikimedia Commons може не мати достатньо фото саме українських лічильників для досягнення заданого ліміту; скрипт повідомить фактичну кількість завантажених файлів.
